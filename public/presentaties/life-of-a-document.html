05 · Breach

The file is out. What does the attacker get?

No label

Everything

Readable and untracked. You can't tell what was in it without a manual search.

Labeled

Known and traced

Still readable, but DLP logged or blocked it, and you know what leaked for the 72-hour GDPR notification.

Labeled + encrypted

Nothing usable

Opens only for authorized identities. Every open is logged and access can be revoked.

If the attacker controls a user's own account, encryption opens for them too. MFA and Conditional Access still matter.

06 · Encryption

Protection tied to identity, not location

Encrypted file

Strong: the protection travels with the file and can be revoked afterwards.

Requirement: every reader needs an account and an app that supports it.
